# NEO-CODEX RPG Portal — v5

Portal cyberpunk de RPG + aprendizagem de programação.

## O que esta versão adiciona

- Compra de personagem → entrada automática na equipe quando há vaga.
- Equipe de até 3 personagens.
- Cada aliado age uma vez por rodada.
- Ataques em alvo único, múltiplos alvos e todos os inimigos.
- Energia para habilidades especiais.
- Sprites SVG de personagens e inimigos.
- Animações de ataque, dano, cura e defesa.
- Capítulos com caixas de diálogo/lore antes do combate.
- Academia com teoria, exemplos e atividades.
- Laboratório para executar/debugar atividades de JavaScript, CSS e Python (Pyodide/CDN), simulador SQL e análise didática de C#.
- Guia completo para adicionar conteúdo.
- Save local via localStorage.

## Rodar

Use um servidor HTTP local (por exemplo, Live Server no VS Code) e abra `index.html`.
